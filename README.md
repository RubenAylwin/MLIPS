## Abstract

MLIPS is a Python framework for efficiently computing failure probabilities through multilevel Monte Carlo-based estimation methods.
It provides modular implementations for different multilevel estimators, including:

1. Monte Carlo Simulation.
2. Multilevel Monte Carlo Simulation.
3. Adaptive Multilevel Monte Carlo Simulation.
4. Multilevel Interacting Particle System Simulation.

The Adaptive Multilevel Monte Carlo Simulation method was proposed in:

```
Elfverson, Hellman, and Målqvist (2016), *A Multilevel Monte Carlo Method for Computing Failure Probabilities*,
SIAM/ASA Journal on Uncertainty Quantification. https://doi.org/10.1137/140984294
```

The Multilevel Monte Carlo method is also analysed in the same article. The Multilevel Interacting Particle System method was proposed
by the authors of this repository in collaboration with colleagues (a research article is currently in preparation).

The goal of the project is to analyze how different sampling strategies converge to the real failure probability.




## 1. Problem Statement

We consider the estimation of a probability of the form:

$
\mathbb{P}_{\mu}[\{f(x)>0\}] = \int \mathbf{1}_{f(x)>0}\mu(dx),
$

in situations where $f(x)$ can only be computed numerically by a sequence of numerical approximations $\{f_\ell\}_{\ell\in\mathbb{N}_0}$
whose precision increases as $\ell$ increases, as well as the computational cost of computing the approximation.

In the next sections we briefly mention how each estimator is computed, for further details we refer to the research article mentioned above and
to our work (currently in preparation).


## 2. Monte Carlo Estimator

The standard (single level) Monte Carlo estimator is computed as:

$
\frac{1}{N} \sum_{i=1}^{N} \mathbb{1}_{f_\ell(x)>0}(x_i).
$


## 3. Multilevel Monte Carlo Estimator

The standard Multilevel Monte Carlo estimator is computed as:

$
\sum_{\ell=0}^{L}\frac{1}{N_\ell} \sum_{i=1}^{N_\ell} \mathbb{1}_{f_\ell(x)>0}(x^{(\ell)}_i)-\mathbb{1}_{f_{\ell-1}(x)>0}(x^{(\ell)}_i),
$

where $\mathbb{1}_{f_{0-1}(x)>0}(x)=0$ for all $x$.
The number of samples per level are chosen so as to minimize the required computational work in order to achieve a certain accuracy.
More details are given in the aforementioned paper (in the context of failure probabilities) and in:

```
Cliffe, Giles, Scheichl, and Teckentrup, *Multilevel Monte Carlo methods and applications to elliptic PDEs with random coefficients*,
Comput. Visual Sci. https://doi.org/10.1007/s00791-011-0160-x
```

## 4. Adaptive Multilevel Monte Carlo Estimator

This method, developed by Elfverson et al., employs a similar estimator as that of the Multilevel Monte Carlo Estimator, but $f_\ell$ is replaced
with an adaptive variant, which computes precise values of $f_{\ell}(x)$ only when its value is close enough to the threshold $0$, arguing that if $f_\ell(x)$ is
far away from $0$, then \mathbb{1}_{f_\ell(x)>0}(x) is exact.


## 5. Multilevel Interacting Particle System
The proposed MLIPS method computes, similar as before, an estimate of the form

$
\sum_{\ell=0}^{L}\hat{p}_\ell\frac{1}{N_\ell} \sum_{i=1}^{N_\ell} \mathbb{1}_{f_\ell(x)>0}(x^{(\ell)}_i)-\mathbb{1}_{f_{\ell-1}(x)>0}(x^{(\ell)}_i),
$

with the difference that $x^{(\ell)}_i$ no longer follows the base probability law $\mu$, but rather are sequentially generated so as to concentrate near the
limit surface $f(y)=0$, since it is only there that the multilevel contributions $\mathbb{1}_{f_\ell(x)>0}(x^{(\ell)}_i)-\mathbb{1}_{f_{\ell-1}(x)>0}(x^{(\ell)}_i)$
may be different from $0$. The factor $\hat{p}_\ell$ is a correcting factor computed from the samples of the previous level ($\hat{p}_0=1$) in order to account for the
bias generated by the sampling strategy.
